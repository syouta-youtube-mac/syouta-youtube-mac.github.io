Privacy Policy

Last updated: 2026-10-29

1. About this tool

Syouta Auto Uploader is a personal, internal-only tool used only by its owner to upload videos the owner creates to the owner's own YouTube channels. No one else signs in or uses it.

2. Use of YouTube API Services

This tool uses the YouTube API Services. By using this tool, users agree to be bound by the YouTube Terms of Service. Google's privacy practices apply to data handled through YouTube API Services; see the Google Privacy Policy (http://www.google.com/policies/privacy).

3. What data is accessed, and why

  • OAuth access to the owner's own YouTube channels (scopes: youtube.upload, youtube.readonly).
  • Used only to upload the owner's videos and thumbnails, and to read the owner's channel name and the time of the latest upload.
  • No data of any other user is accessed, collected, stored, or shared.

4. Storage and sharing

  • OAuth refresh tokens are stored only in the owner's macOS Keychain and in a private execution environment used only by the owner.
  • No data is sold or shared with third parties. No cookies or tracking are used by this tool.

5. Deletion and revoking access

  • Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
  • When access is revoked or the tool is no longer used, the stored tokens are deleted from the Keychain and the execution environment. Any API data the tool keeps (upload records) is deleted within 30 days.

6. Contact

Questions: via the GitHub profile of the owner, syouta-youtube-mac.
